# Система екологічного моніторингу (Python)

Імітаційний прототип системи екологічного моніторингу на мові Python.

## Опис

Система демонструє взаємодію між основними учасниками процесу екологічного моніторингу:
- Оператор станції
- Еколог
- Диспетчер ДСНС

## Запуск

1. Переконайтесь, що встановлено Python 3.10+  
2. Покладіть файли з класами поруч з файлом `main.py`, наприклад:
   - `person.py`
   - `service_planner.py`
   - `dispatcher.py`
   - `ecologist.py`
   - `operator.py`
   - `event.py`
   - `measure.py`
   - `main.py`

3. Запустіть програму командою з каталогу проєкту:
   ```bash
   python main.py
