# Ecomonitoring Project

## Призначення проекту

Цей проект є системою моніторингу екологічних показників, де оператори, екологи та диспетчери взаємодіють для контролю і управління станом екологічної ситуації в різних зонах. При перевищенні норм виявляються події, які зберігаються в базі даних.

Основні функції:
- Оператор проводить моніторинг даних.
- Еколог аналізує показники і перевіряє перевищення норм.
- Диспетчер отримує сповіщення про перевищення і зберігає їх у базу даних.

## Структура проекту

- **`src/main/java/com/ecomonitoring/`** — основний код Java.
    - **`Main.java`** — головний клас для запуску системи.
    - **`Dispatcher.java`** — клас диспетчера, що отримує сповіщення.
    - **`EventService.java`** — сервіс для збереження подій у базу даних.
    - **`EcomonitoringModule.java`** — клас для конфігурації впровадження залежностей через Guice.
- **`src/test/java/com/ecomonitoring/`** — тести для проекту.
    - **`AppTest.java`** — тестовий клас для перевірки базових функцій проекту.
